# Codex Workflow Kit v0.1.0-beta

Publication status and verification references are maintained in [the beta tasks](../../.doc/specs/public-core/tasks.md).

This first beta packages eight focused Codex workflows with independent cwk names, optional project rules, and evidence-based verification. It preserves project documentation conventions and existing authorization. Kiro and delegation preferences are optional; installation does not change global rules, model settings or other workflow plugins.

## Included

- cwk-route, cwk-design, cwk-plan, cwk-execute, cwk-tdd, cwk-debug, cwk-review and cwk-verify, together with their required references.
- Native Codex marketplace installation, versioned updates and removal.
- Optional core, Kiro and explicit-delegation rule fragments in the source repository.
- Deterministic packaging, offline checks and sanitized real-session evaluation evidence in the source repository.

## Installation

The tested baseline is Codex CLI 0.153.4 on macOS arm64. Download `codex-workflow-kit-0.1.0-beta.zip` and its `.sha256` file into the same directory. Verify and extract:

```sh
shasum -a 256 -c codex-workflow-kit-0.1.0-beta.zip.sha256
unzip codex-workflow-kit-0.1.0-beta.zip -d codex-workflow-kit-0.1.0-beta
cd codex-workflow-kit-0.1.0-beta
codex plugin marketplace add .
codex plugin add codex-workflow-kit@codex-workflow-kit
codex plugin list --marketplace codex-workflow-kit --json
```

Keep the extracted marketplace directory available for future reinstalls. Start a new Codex session in your project and try `Use $cwk-route to choose the workflow for this task.` For ordinary wording changes, ask directly.

The archive SHA-256 is `69e727f9888ac92a48dff0f9365f8544411965488f0dce59ca5938ea7f3742ea`. The archive contains the complete runtime plugin; optional rule templates, development tools and evaluation evidence remain in the source repository. `BUNDLE.json` records individual packaged file hashes.

See [adoption](../adoption.md) for updates and rollback. To remove the plugin and its marketplace registration:

```sh
codex plugin remove codex-workflow-kit@codex-workflow-kit
codex plugin marketplace remove codex-workflow-kit
```

Manually adopted project rules remain under your control.

## Validation and Limits

Local evidence includes 52 offline tool tests, native install/discovery/update/removal checks, actual Superpowers v6.3.0 coexistence, 20/20 selection cases for the final catalog, and eight distinct real task scenarios. The earlier 18/20 and 19/20 selection runs are retained alongside the targeted fixes. See [validation](../validation.md) for exact settings, scope and pending release gates.

Selection observations do not measure automatic host loading or guarantee behavior for every prompt. Actual tasks used the existing configured provider with requested gpt-6-astra and high reasoning effort; the provider's backend implementation was not independently attested. No speed, cost or quality superiority is claimed.

Desktop UI installation, Linux/Windows host installation, other CLI versions and other models remain unverified. If Superpowers is installed, choose one workflow provider per task; distinct names prevent collisions but do not resolve contradictory project instructions.
