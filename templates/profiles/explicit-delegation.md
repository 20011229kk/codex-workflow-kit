# Optional Explicit-Delegation Preference

For users who prefer inline execution and explicit control over subagent cost and context sharing. Host and project authorization boundaries still apply.

- Complete work in the current session by default without a separate execution-mode question.
- Delegate only when the user explicitly requests subagents. Preserve an existing unchanged choice within its authorized scope.
- Delegate only bounded, independently executable work. Provide necessary requirements and original evidence rather than the implementer's expected verdict.
- If high-risk work needs independent review but delegation is not authorized, ask once for that review decision or record pending human review. Continue independent implementation and verification; do not substitute self-review for independence.
